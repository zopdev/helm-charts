No public URL is configured, so n8n falls back to http://localhost:5678/ and
every webhook it registers will carry that address. Before building anything
webhook-triggered, set one:

  --set ingress.enabled=true --set ingress.host=n8n.example.com

or, if something else already terminates traffic for you:

  --set webhookUrl=https://n8n.example.com/

{{ if not .Values.encryptionKey.existingSecret }}
The credential encryption key was generated into secret
{{ include "n8n.encryptionSecretName" . }}. Every credential stored in n8n is
encrypted with it, and it cannot be recovered from the database. Back it up now:

  kubectl get secret -n {{ .Release.Namespace }} \
    {{ include "n8n.encryptionSecretName" . }} \
    -o jsonpath='{.data.{{ .Values.encryptionKey.secretKey }}}' | base64 -d

Upgrades read the existing key back rather than generating a new one, and the
secret carries helm.sh/resource-policy: keep so `helm uninstall` leaves it behind.

Use `helm upgrade` to keep an instance alive. Uninstall-and-reinstall does NOT
work over the retained volumes: the postgres root secret is not retained, so the
new one will not match the existing data directory. Back up this secret and
{{ .Release.Name }}-postgres-root-secret together if you ever intend to restore.
{{- end }}
