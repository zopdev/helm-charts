listmonk is starting. The first start creates the database schema and the
admin account, so the pod can take a minute or two to become Ready.

Sign in as "{{ .Values.admin.username }}" with the password
{{- if .Values.admin.password }} you set in admin.password.
{{- else }} generated into a Secret:

  kubectl get secret {{ .Release.Name }}-admin -n {{ .Release.Namespace }} \
    -o jsonpath='{.data.LISTMONK_ADMIN_PASSWORD}' | base64 -d; echo
{{- end }}

The account is created once. To change the password later, use
Admin -> Users in listmonk; editing admin.* afterwards has no effect.
{{- if .Values.service.nginx.host }}

Open: http{{ if .Values.service.nginx.tlsSecretName }}s{{ end }}://{{ .Values.service.nginx.host }}/admin
{{- else }}

Open it locally:

  kubectl port-forward svc/{{ .Values.service.name }} -n {{ .Release.Namespace }} 9000:80
  # http://localhost:9000/admin
{{- end }}

Then set Settings -> General -> Root URL to the public address; listmonk puts
it in every unsubscribe and tracking link it sends.
