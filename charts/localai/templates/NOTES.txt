Workers register themselves on startup.
{{- if .Values.distributed.autoApproveNodes }}
They are approved automatically.
{{- else }}
They stay `pending` until approved, and receive no traffic before that.
Approve them from the Nodes page in the web UI.
{{- end }}

Distributed mode runs with authentication on, because LocalAI only opens
its PostgreSQL-backed state that way. The API, /api/nodes/ included,
answers 401 without a key. To confirm the workers joined without one,
read it from the pods instead:

  kubectl logs -n {{ .Release.Namespace }} \
    -l app.kubernetes.io/component=worker --tail=-1 \
    | grep "Registered with frontend"

The registration token is generated into a Secret. Read it with:

  kubectl get secret -n {{ .Release.Namespace }} \
    {{ include "localai.registrationSecretName" . }} \
    -o jsonpath='{.data.registration-token}' | base64 -d
{{- end }}

No models are installed by default. Install one from the gallery, e.g.:

  curl http://localhost:8080/models/apply \
    -H 'Content-Type: application/json' \
    -d '{"id": "localai@qwen3-1.7b"}'
